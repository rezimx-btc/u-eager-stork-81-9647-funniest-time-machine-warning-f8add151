My entry for the "Funniest Time Machine Warning Label" bounty on make.fun: a one-line warning label for time travelers. The joke follows the classic rule → violation → restore shape — break the one rule (never meet your younger self) and the timeline treats *you* as the bug, hotfixing you out of existence.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It uses only the Python standard library.
